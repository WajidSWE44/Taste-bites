# 🍽️ Taste Bites – Restaurant Website

**Taste Bites** is a restaurant website built using HTML, CSS, and JavaScript. It provides a user-friendly interface for exploring food items, managing a shopping cart, making reservations, and accessing restaurant-related features.

## 🌐 Project Overview

Taste Bites is designed to provide customers with a simple and convenient online restaurant experience. The website includes customer-facing pages and an administration interface.

## ✨ Features

- **Home Page:** Restaurant introduction and featured content.
- **Food Menu:** Browse available food items.
- **Food Details:** View individual food information.
- **Shopping Cart:** Add and manage selected food items.
- **User Authentication:** Login and registration pages.
- **Reservations:** Restaurant table reservation interface.
- **Order Tracking:** Track order information.
- **About Us:** Information about the restaurant.
- **Contact Us:** Customer contact interface.
- **Admin Panel:** Administrative interface for restaurant management.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/WajidSWE44/Taste-bites.git
```

### 2. Navigate to the project folder

```bash
cd Taste-bites
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the website

```bash
npm run dev
```
